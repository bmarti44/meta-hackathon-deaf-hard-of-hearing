## 3. THE PROTOCOL — per-pin extraction + evaluability rule

Common discipline (all pins): **human dual extraction**
(agent pre-extraction = triage only, never deciding);
every value carries source, locator (document + page/
section/table), device name + era, and extraction date;
discrepancies adjudicated by a named third human before
any pin is declared filed; sources ranked primary
(regulatory labelling / manufacturer specification for the
named device) > standards/consensus > peer-reviewed
secondary; a value from a *different* device is context,
never a pin. Extraction happens **before** any further
model output is opened (A1 blinding discipline inherited).

| # | Pin (A1 S3 placeholder it discharges) | Extraction fields | "Filed" rule (pre-stated) |
|---|---|---|---|
| P-1 | Named device / array / contacts | Manufacturer, model, era; per-contact area (mm²); array geometry source | One primary source naming all fields for one device; no cross-device assembly |
| P-2 | Safe-charge limit procedure | Manufacturer max charge density (µC/cm²/phase) for P-1 contacts; tissue-damage threshold source; safety-margin divisor + its source | Limit = min(manufacturer max, threshold ÷ margin) computable from filed fields; two-route agreement within pre-stated tolerance **or** single primary source per field; any field secondary-only ⇒ pin provisional, kill still UNEVALUABLE |
| P-3 | Battery floor | Processor hours/day minimum + the map levels (pps, pulse width, maxima) it assumes, for P-1's processor | Primary spec stating hours *at stated levels*; a floor without levels (or levels without hours) = not filed |
| P-4 | Growing-cochlea geometry set | Dimension source(s) by pre-stated ages; electrode–modiolus distance derivation per age | Cited dimensions covering every pre-stated age in A1 S3, or the missing ages declared and those strata marked INSUFFICIENT — no interpolation invented at extraction |
| P-5 | Fibrosis grade rubric (model-implementable) | Seyyedi & Nadol 0–3 verbal scale (already located, verbal-only) → per-grade conductivity/thickness mapping the model actually uses, with source per grade | Every grade 0–3 mapped from a cited source; any grade mapped by modeller's choice alone ⇒ that grade's sweep rows labelled assumption-sensitivity, kill evaluable only if the verdict (S12) is invariant across them — pre-stated, not argued after |
| R-1 | Convergence criterion (ruling, holder/human) | Pre-stated quantitative criterion (e.g. max relative change in endpoint between successive halvings) chosen **before** any new solve | Criterion on file, signed, dated before outputs; absent ⇒ no new solve is licensed at all |
